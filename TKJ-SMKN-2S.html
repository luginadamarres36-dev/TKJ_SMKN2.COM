Merakit dan membongkar komputer

Pakai gelang antistatik atau sentuh logam casing dulu untuk membuang listrik statis. Urutan merakit:

  1. Pasang CPU ke soket. Sejajarkan tanda segitiga di CPU dengan di soket.
  2. Oleskan pasta termal tipis, lalu pasang heatsink dan kipas.
  3. Pasang RAM sampai kedua pengaitnya berbunyi klik.
  4. Pasang SSD (slot M.2 atau kabel SATA).
  5. Pasang motherboard ke casing dengan standoff dan baut.
  6. Pasang PSU, sambungkan kabel 24-pin ke motherboard dan kabel CPU 4/8-pin.
  7. Sambungkan kabel panel depan (power, reset, USB, audio).
  8. Hubungkan monitor, keyboard, lalu nyalakan untuk tes.

Membongkar berarti mengulang langkah di atas dari belakang, dan cabut kabel listrik lebih dulu.

Instalasi Windows dan Linux
  1. Buat flashdisk bootable dengan Rufus atau Ventoy dari file ISO.
  2. Masuk BIOS/UEFI (biasanya tekan Del, F2, atau F12) dan pilih flashdisk sebagai boot pertama.
  3. Ikuti installer: pilih bahasa, partisi, lalu tunggu proses salin file.
  4. Setelah restart, pasang driver dan update sistem.

Windows memakai installer grafis dan butuh lisensi. Linux (misalnya Ubuntu atau Debian) gratis dan bisa dicoba dulu lewat mode Live sebelum diinstal.

Cara kerja komputer dan satuan data

Semua komputer bekerja dengan alur yang sama: input (data masuk lewat keyboard, mouse, mikrofon), proses (CPU mengolah, RAM menampung sementara), output (hasil tampil di monitor atau keluar di speaker, printer), dan penyimpanan (file disimpan di SSD atau HDD).

Komputer hanya mengerti dua keadaan: 0 dan 1, disebut bit. Satuan yang perlu dihafal:

  • 1 byte = 8 bit
  • 1 KB = 1024 byte, 1 MB = 1024 KB, 1 GB = 1024 MB, 1 TB = 1024 GB

Hati-hati membedakan B (byte) dan b (bit). Kecepatan internet biasanya dalam bit per detik (Mbps), sedangkan ukuran file dalam byte. Jadi 100 Mbps kira-kira 12,5 MB per detik.

Komponen pendukung, port, dan BIOS/UEFI
  • GPU (kartu grafis): mengolah gambar dan video. Ada yang menyatu dengan CPU (integrated), ada yang terpisah (dedicated).
  • Heatsink dan kipas: membuang panas CPU. Pasta termal mengisi celah kecil antara CPU dan heatsink supaya panas mengalir lancar.
  • Casing: rumah komponen, juga mengatur aliran udara.

Port yang sering ditemui: USB (perangkat umum), HDMI dan DisplayPort (video digital), VGA (video analog, perangkat lama), RJ45 (kabel LAN), dan jack audio.

BIOS/UEFI adalah program kecil di motherboard yang pertama jalan saat komputer dinyalakan. Tugasnya memeriksa hardware lalu memulai booting sistem operasi. Di sini kamu juga mengatur urutan boot, jam, dan mode penyimpanan.

Dasar-Dasar Jaringan Komputer

Jenis jaringan, bentuk hubungannya, dan perangkat yang dipakai.

LAN, MAN, WAN, dan WLAN
  • LAN: jaringan area terbatas, seperti satu ruangan, lab, atau gedung.
  • MAN: mencakup satu kota atau kawasan luas.
  • WAN: menghubungkan jaringan antarkota atau antarnegara. Internet adalah WAN terbesar.
  • WLAN: LAN tanpa kabel, atau yang kita kenal sebagai Wi-Fi.

Membuat kabel LAN straight dan crossover

Alat: kabel UTP, konektor RJ45, crimping tool, dan LAN tester. Urutan warna pin 1 sampai 8:

T568B

T568A

  • Straight: kedua ujung T568B. Dipakai untuk perangkat berbeda jenis, misalnya PC ke switch.
  • Crossover: satu ujung T568B, ujung lain T568A. Dipakai untuk perangkat sejenis, misalnya PC ke PC.

Perangkat modern umumnya punya Auto MDI-X sehingga kabel straight sudah cukup untuk hampir semua kasus.

Switch, router, dan access point
  • Switch: menghubungkan perangkat dalam satu jaringan dan meneruskan data berdasarkan MAC address.
  • Router: menghubungkan jaringan yang berbeda, misalnya jaringan sekolah ke internet, berdasarkan IP address.
  • Access point: memancarkan sinyal Wi-Fi dari jaringan kabel supaya perangkat nirkabel bisa terhubung.

Pengingat urutan dari atas: All People Seem To Need Data Processing. Dalam praktik, internet memakai model TCP/IP yang lebih ringkas, yaitu 4 lapisan: Application, Transport, Internet, dan Network Access.

TCP menjamin data sampai lengkap dan berurutan (dipakai web dan email). UDP lebih cepat tapi tanpa jaminan (dipakai video call dan game).

IP Addressing dan Subnetting

Cara perangkat saling menemukan, dan cara membagi jaringan.

IPv4 dan IPv6
  • IPv4: 32 bit, ditulis 4 angka desimal (0 sampai 255) dipisah titik, contoh 192.168.1.10. Jumlahnya terbatas sekitar 4,3 miliar.
  • IPv6: 128 bit, ditulis heksadesimal dipisah titik dua, contoh 2001:db8::1. Jumlahnya hampir tak terbatas.
IP address, subnet mask, gateway, dan DNS
  • IP address: alamat unik perangkat di jaringan.
  • Subnet mask: pembeda bagian network dan bagian host dari IP, contoh 255.255.255.0 (ditulis juga /24).
  • Gateway: pintu keluar ke jaringan lain, biasanya IP router.
  • DNS: menerjemahkan nama domain (google.com) menjadi IP address.
Menghitung subnetting

Rumus jumlah host per subnet: 2^(32 - prefix) - 2. Dikurangi 2 karena alamat pertama untuk network dan terakhir untuk broadcast.

Contoh 192.168.1.0/26: mask 255.255.255.192, tiap subnet punya 2^6 - 2 = 62 host, ukuran blok 64. Subnetnya mulai dari .0, .64, .128, dan .192.

Coba hitung sendiri:

DHCP dan konfigurasi IP statis
  • DHCP: server yang membagikan IP, mask, gateway, dan DNS secara otomatis. Cocok untuk laptop dan HP.
  • IP statis: diatur manual. Cocok untuk server, printer, dan router karena alamatnya tidak boleh berubah.

Contoh IP statis satu jaringan:

  • IP: 192.168.1.10
  • Mask: 255.255.255.0
  • Gateway: 192.168.1.1
  • DNS: 8.8.8.8
Praktik di Cisco Packet Tracer
  1. Tambahkan 1 switch dan 2 PC ke area kerja.
  2. Hubungkan PC ke switch dengan kabel Copper Straight-Through.
  3. Klik PC, buka Desktop > IP Configuration, isi IP statis: PC0 192.168.1.10 dan PC1 192.168.1.11, mask 255.255.255.0.
  4. Buka Command Prompt di PC0 dan jalankan ping 192.168.1.11.
  5. Balasan "Reply from" berarti jaringanmu berhasil.
Kelas IP, IP privat, dan IP publik
KelasOktet pertamaMask bawaan
A1 sampai 126/8 (255.0.0.0)
B128 sampai 191/16 (255.255.0.0)
C192 sampai 223/24 (255.255.255.0)

Alamat 127.x.x.x khusus untuk komputer sendiri (loopback), misalnya 127.0.0.1.

IP privat dipakai di dalam jaringan lokal dan tidak dikenal di internet:

  • 10.0.0.0 sampai 10.255.255.255
  • 172.16.0.0 sampai 172.31.255.255
  • 192.168.0.0 sampai 192.168.255.255

Alamat lain adalah IP publik, dibagikan oleh ISP. Kalau komputer tidak mendapat IP dari DHCP, Windows memberi alamat darurat 169.254.x.x (APIPA). Jika melihat alamat ini, berarti DHCP tidak terjangkau.

Mengubah biner dan desimal

Setiap oktet IP terdiri dari 8 bit dengan nilai posisi:

128  64  32  16  8  4  2  1

Jumlahkan nilai posisi yang bernilai 1. Contoh:

  • 192 = 128 + 64 = 11000000
  • 168 = 128 + 32 + 8 = 10101000
  • 224 = 128 + 64 + 32 = 11100000

Subnet mask selalu berisi angka 1 berurutan lalu 0. Prefix /26 berarti 26 bit pertama bernilai 1:

11111111.11111111.11111111.11000000
= 255.255.255.192
Contoh subnetting langkah demi langkah

Soal: bagi jaringan 192.168.5.0/24 menjadi 8 subnet sama besar.

  1. 8 subnet = 2^3, jadi pinjam 3 bit dari bagian host. Prefix baru: 24 + 3 = /27.
  2. Mask baru: 255.255.255.224 (11100000 = 224).
  3. Ukuran blok: 256 - 224 = 32. Subnet mulai dari .0, .32, .64, dan seterusnya.
  4. Host per subnet: 2^5 - 2 = 30.
SubnetNetworkRentang hostBroadcast
1.0.1 sampai .30.31
2.32.33 sampai .62.63
3.64.65 sampai .94.95
...dan seterusnya dengan selisih 32
8.224.225 sampai .254.255

Rumusnya: network = alamat pertama blok, broadcast = alamat terakhir blok, host = di antara keduanya. Cek hasilmu dengan kalkulator di atas.

Konfigurasi Router dan MikroTik

Perintah RouterOS lewat Terminal atau WinBox. Sesuaikan nama interface (di sini ether1 = internet, ether2 = LAN).

IP address dan gateway
/ip address add address=192.168.1.2/24 interface=ether1
/ip address add address=192.168.10.1/24 interface=ether2
/ip route add dst-address=0.0.0.0/0 gateway=192.168.1.1
/ip dns set servers=8.8.8.8 allow-remote-requests=yes

Baris ketiga adalah default gateway ke arah internet. Kalau internet dari ISP otomatis, pakai /ip dhcp-client add interface=ether1 disabled=no.

Routing statis

Memberi tahu router cara mencapai jaringan lain lewat router tetangga:

/ip route add dst-address=10.10.10.0/24 gateway=192.168.1.254

Artinya: untuk tujuan 10.10.10.0/24, kirim paket lewat 192.168.1.254. Cek dengan /ip route print.

DHCP Server
/ip pool add name=pool-lan ranges=192.168.10.10-192.168.10.200
/ip dhcp-server add name=dhcp-lan interface=ether2 address-pool=pool-lan disabled=no
/ip dhcp-server network add address=192.168.10.0/24 gateway=192.168.10.1 dns-server=192.168.10.1

Klien di ether2 kini mendapat IP, gateway, dan DNS otomatis. Lihat daftarnya di /ip dhcp-server lease print.

NAT agar klien bisa ke internet
/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade

NAT masquerade mengganti IP privat klien (192.168.10.x) dengan IP publik router saat keluar ke internet. Tanpa aturan ini, klien bisa ping router tapi tidak bisa membuka internet.

Firewall dasar dan manajemen bandwidth
/ip firewall filter
add chain=input connection-state=established,related action=accept
add chain=input connection-state=invalid action=drop
add chain=input in-interface=ether1 action=drop

Urutan penting: aturan dibaca dari atas. Aturan terakhir memblokir akses ke router dari sisi internet, jadi pastikan kamu mengelola router lewat LAN.

Membatasi bandwidth satu klien dengan Simple Queue (format upload/download):

/queue simple add name=limit-pc1 target=192.168.10.50/32 max-limit=2M/5M
Mengenal RouterOS, WinBox, dan perintah dasar

MikroTik memakai sistem operasi RouterOS. Ada tiga cara mengaksesnya: WinBox (aplikasi grafis, bisa terhubung lewat MAC address saat router belum punya IP), WebFig (lewat browser), dan Terminal atau SSH (perintah teks).

Router MikroTik baru umumnya punya konfigurasi bawaan dengan IP 192.168.88.1, user admin, dan password kosong atau sesuai stiker di router. Ganti password sebelum dipakai.

Urutan konfigurasi router untuk jaringan sekolah
  1. Pastikan router mendapat internet di port WAN (ether1), lalu tes /ping 8.8.8.8.
  2. Beri IP pada port LAN (ether2).
  3. Atur DNS router.
  4. Aktifkan NAT masquerade.
  5. Buat DHCP server untuk LAN.
  6. Tes dari komputer klien: dapat IP, bisa ping gateway, bisa ping 8.8.8.8, bisa membuka situs.
  7. Pasang firewall dasar dan batasi bandwidth bila perlu.
  8. Terakhir, simpan backup konfigurasi.

Kerjakan satu langkah, tes, baru lanjut. Kalau gagal, kamu langsung tahu langkah mana penyebabnya.

Administrasi Sistem dan Server

Menyiapkan server dan layanan yang dipakai jaringan sehari-hari.

Instalasi Linux Server dan Windows Server
  • Linux Server (Ubuntu Server atau Debian): biasanya tanpa tampilan grafis, dikelola lewat terminal dan SSH. Saat instalasi atur hostname, IP statis, dan buat user.
  • Windows Server: punya tampilan grafis. Layanan ditambah lewat Server Manager > Add Roles and Features.

Setelah instalasi, update sistem dan catat IP server.

Konfigurasi web server
sudo apt update
sudo apt install apache2
sudo systemctl status apache2

Folder halaman webnya /var/www/html. Buka http://IP-server dari browser klien untuk mengetes. Alternatifnya Nginx. Di Windows Server, web server memakai role IIS.

DNS Server dan DHCP Server

DNS di Linux memakai BIND9 (sudo apt install bind9): kamu membuat zona, lalu mencatat nama seperti web.sekolah.local mengarah ke IP server. Di Windows Server, pakai role DNS Server.

DHCP di Linux memakai isc-dhcp-server. Isi dasar /etc/dhcp/dhcpd.conf:

subnet 192.168.10.0 netmask 255.255.255.0 {
  range 192.168.10.100 192.168.10.200;
  option routers 192.168.10.1;
  option domain-name-servers 192.168.10.2;
}

Jangan jalankan dua DHCP server di jaringan yang sama, nanti klien mendapat IP bentrok.

File server dan user management

Di Linux, berbagi folder ke Windows memakai Samba:

sudo apt install samba
sudo adduser budi
sudo smbpasswd -a budi
sudo usermod -aG guru budi
sudo chmod 770 /data/guru

Perintah itu membuat user, memberi password Samba, memasukkannya ke grup, dan membatasi folder hanya untuk pemilik dan grup. Di Windows Server, bagikan folder lewat Share dan atur izin NTFS per user atau grup. Prinsipnya sama: beri hak sesuai kebutuhan saja.

Virtualisasi dengan VirtualBox atau VMware

Virtualisasi menjalankan beberapa komputer virtual (guest) di satu komputer asli (host). Cocok untuk latihan server tanpa perangkat tambahan.

  1. Buat VM baru, pilih file ISO sistem operasi.
  2. Atur RAM, jumlah CPU, dan ukuran disk virtual.
  3. Pilih mode jaringan, lalu instal seperti biasa.
Mode jaringanFungsi

BridgedVM dapat IP di jaringan yang sama dengan host.

Hak akses file terdiri dari tiga kelompok (pemilik, grup, lainnya), masing-masing berisi r (baca, 4), w (tulis, 2), x (jalankan, 1). Contoh:

  • chmod 755 = rwxr-xr-x: pemilik penuh, yang lain hanya baca dan jalankan.
  • chmod 770 = rwxrwx---: pemilik dan grup penuh, yang lain tidak boleh.

Hati-hati dengan rm -r: file yang dihapus tidak masuk tempat sampah.

Mengelola layanan dan praktik web server
sudo systemctl start apache2
sudo systemctl stop apache2
sudo systemctl restart apache2
sudo systemctl enable apache2
sudo systemctl status apache2

enable membuat layanan otomatis jalan saat server dinyalakan. Kalau layanan bermasalah, lihat lognya: sudo journalctl -u apache2.

Praktik singkat:

  1. Pasang Apache, pastikan statusnya active (running).
  2. Edit halaman: sudo nano /var/www/html/index.html, isi dengan HTML sederhana.
  3. Dari komputer klien, buka http://IP-server.
  4. Kalau tidak muncul, cek IP server, firewall (port 80), dan status layanan.

Teknologi Jaringan Kabel dan Fiber Optik

Memilih media, memasang konektor, dan mengujinya.

Kabel UTP dan fiber optik
  • UTP: kabel tembaga berisi 4 pasang kabel, membawa sinyal listrik. Maksimal 100 meter per segmen. Cat5e untuk 1 Gbps, Cat6 untuk 1 Gbps (10 Gbps sampai sekitar 55 meter), Cat6a untuk 10 Gbps sampai 100 meter.
  • Fiber optik: serat kaca yang membawa cahaya. Jaraknya jauh, kecepatannya tinggi, dan kebal gangguan listrik.
Jenis fiberCiri
Single-modeInti sangat kecil (sekitar 9 mikron), laser, jarak puluhan kilometer.
Multi-modeInti lebih besar (50 atau 62,5 mikron), jarak pendek, cocok antargedung dan di dalam gedung.
Konektor RJ45 dan konektor fiber
  • RJ45: konektor 8 pin untuk kabel UTP.
  • SC: persegi, dipasang dengan didorong (push-pull).
  • LC: versi kecil dari SC, umum di modul SFP.
  • ST: bulat dengan kunci putar bayonet.
  • FC: bulat dengan ulir sekrup.
Teknik pemasangan dan pengujian

UTP:

  1. Kupas jaket kabel sekitar 2 sampai 3 cm.
  2. Urutkan kabel sesuai T568B, rapikan, potong rata.
  3. Masukkan ke RJ45 sampai ujung kabel terlihat di ujung konektor.
  4. Jepit dengan crimping tool, lalu uji dengan LAN tester. Lampu 1 sampai 8 harus menyala berurutan.

Fiber: disambung dengan fusion splicer atau dipasang konektor, memakai alat cleaver dan stripper. Pengujian dengan VFL (senter merah untuk melihat patahan), power meter, dan OTDR untuk mengukur panjang serta titik gangguan.

Keselamatan: jangan melihat langsung ujung fiber yang sedang menyala, dan buang serpihan kaca di wadah khusus.

Dasar jaringan nirkabel dan Wi-Fi

Wi-Fi memakai standar IEEE 802.11. Dua pita frekuensi utama:

PitaCiri
2,4 GHzJangkauan luas, lebih mudah menembus dinding, tapi ramai dan rawan interferensi. Kanal yang tidak saling tumpang tindih: 1, 6, 11.
5 GHzLebih cepat dan lebih sepi, tapi jangkauan lebih pendek.

Generasi umum: 802.11n (Wi-Fi 4), ac (Wi-Fi 5), dan ax (Wi-Fi 6).

  • Atur SSID dan keamanan WPA2 atau WPA3. Hindari jaringan terbuka dan WEP.
  • Letakkan access point di tengah area, agak tinggi, jauh dari dinding tebal dan microwave.
Alat kerja dan instalasi kabel terstruktur
  • Crimping tool: menjepit konektor RJ45 ke kabel.
  • Cable stripper: mengupas jaket kabel tanpa melukai kabel di dalamnya.
  • LAN tester: memeriksa 8 jalur kabel.
  • Punch-down tool: menekan kabel ke patch panel atau keystone jack.

Pada gedung besar, kabel dipasang secara terstruktur: kabel dari ruangan (outlet di dinding) ditarik ke patch panel di rak (rack), lalu dihubungkan ke switch memakai patch cord pendek. Dengan begitu perpindahan atau perbaikan cukup dilakukan di rak, tanpa menarik kabel baru.

Tips pemasangan: jangan menekuk kabel terlalu tajam, jauhkan dari kabel listrik, beri label di kedua ujung, dan sisakan panjang cadangan.

Kekuatan sinyal Wi-Fi dan masalah umum

Kekuatan sinyal diukur dalam dBm, nilainya negatif. Makin mendekati nol, makin kuat:

SinyalKualitas
-50 dBm atau lebih kuatSangat baik
-60 sampai -70 dBmCukup baik
-80 dBm atau lebih lemahSering putus

Penyebab Wi-Fi lambat atau putus: jarak terlalu jauh, dinding tebal, kanal bertabrakan dengan Wi-Fi tetangga, terlalu banyak perangkat, atau interferensi dari microwave dan Bluetooth. Gunakan aplikasi Wi-Fi analyzer untuk melihat kanal mana yang sepi, lalu pindahkan access point ke kanal itu.

Menyembunyikan SSID dan filter MAC address bukan pengamanan yang kuat. Yang utama tetap WPA2 atau WPA3 dengan password panjang.

Keamanan Jaringan

Melindungi perangkat, akun, dan data, lalu tahu cara mencari tahu kalau ada yang salah.

Firewall dan kontrol akses

Firewall menyaring lalu lintas berdasarkan aturan. Prinsipnya: blokir semua dulu, lalu izinkan hanya yang dibutuhkan. Contoh di Linux dengan UFW:

sudo ufw default deny incoming
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw enable

Izinkan port SSH (22) sebelum enable, supaya kamu tidak terkunci dari server sendiri. Kontrol akses juga berarti memisahkan jaringan, misalnya Wi-Fi tamu dipisah dari jaringan kantor atau lab (segmentasi atau VLAN).

Mengamankan router dan server
  • Ganti password bawaan dan buat user admin sendiri, lalu nonaktifkan user default.
  • Matikan layanan yang tidak dipakai. Di MikroTik: /ip service disable telnet,ftp,www
  • Batasi akses manajemen hanya dari LAN: /ip service set winbox address=192.168.10.0/24
  • Di server, pakai SSH dengan kunci (key) dan set PermitRootLogin no di /etc/ssh/sshd_config.
  • Update firmware RouterOS dan paket server secara berkala.
  • Simpan backup konfigurasi di tempat terpisah.
Password kuat dan pengelolaan hak akses
  • Pakai password panjang (minimal 12 karakter), misalnya kalimat acak yang mudah kamu ingat.
  • Satu akun satu password. Simpan di password manager dan aktifkan verifikasi dua langkah bila ada.
  • Least privilege: beri hak akses sekecil yang dibutuhkan pekerjaannya.
  • Pisahkan akun admin dari akun harian, tinjau daftar user berkala, dan hapus akun yang sudah tidak dipakai.
Mendeteksi dan mengatasi gangguan jaringan

Cari penyebab dari dekat ke jauh:

TesKalau gagal, curigai
ping 127.0.0.1Pengaturan jaringan di perangkat itu sendiri.
Ping IP gatewayKabel, switch, atau IP/mask yang salah.
ping 8.8.8.8Router, NAT, atau koneksi ISP.
ping google.comDNS.

Alat bantu: traceroute, ipconfig atau ip a, log (/log print di MikroTik, journalctl di Linux), dan Wireshark untuk melihat isi lalu lintas.

Tanda gangguan keamanan: banyak login gagal, trafik melonjak tanpa sebab, atau ada perangkat asing di daftar DHCP. Penanganannya: isolasi perangkat, ganti password, tutup celah (update atau aturan firewall), lalu catat kejadiannya.

Jenis ancaman umum dan pencegahannya
AncamanPenjelasanPencegahan
MalwareProgram berbahaya (virus, ransomware).Antivirus, update, jangan pasang software bajakan.
PhishingPesan atau situs palsu untuk mencuri password.Periksa alamat pengirim dan URL, jangan klik tautan mencurigakan.

Checklist keamanan dasar dan backup
  • Update sistem dan firmware secara rutin.
  • Matikan layanan dan port yang tidak dipakai.
  • Pakai SSH, bukan Telnet.
  • Aktifkan log dan baca sesekali.
  • Batasi hak akses sesuai kebutuhan (least privilege).

Aturan backup 3-2-1: simpan 3 salinan data, di 2 jenis media berbeda, dan 1 salinan di tempat lain. Backup yang belum pernah dicoba dikembalikan belum bisa dianggap aman, jadi uji sesekali.

Dasar database dan SQL

Database menyimpan data dalam tabel (baris dan kolom). SQL adalah bahasa untuk mengelolanya. Contoh daftar perangkat:

CREATE TABLE perangkat (id INTEGER PRIMARY KEY, nama TEXT, ip TEXT);
INSERT INTO perangkat (nama, ip) VALUES ('Router', '192.168.1.1');
SELECT * FROM perangkat WHERE ip LIKE '192.168.1.%';
UPDATE perangkat SET nama = 'Router Utama' WHERE id = 1;
DELETE FROM perangkat WHERE id = 1;

Untuk latihan, SQLite sudah cukup: ringan dan tidak butuh server.

Script sederhana untuk admin jaringan

Mengecek perangkat mana yang aktif di jaringan sendiri:

import subprocess

for i in range(1, 11):
    ip = f"192.168.1.{i}"
    hasil = subprocess.run(["ping", "-c", "1", "-W", "1", ip],
                           capture_output=True)
    print(ip, "hidup" if hasil.returncode == 0 else "tidak merespons")

Di Windows, ganti -c dengan -n dan hapus -W 1. Pakai hanya di jaringan milikmu. Ide script lain: backup konfigurasi router berkala, atau mencatat hasil ping ke database SQL.

Python lebih lanjut: tipe data, list, dan dictionary

Tipe data dasar: str (teks), int (bilangan bulat), float (desimal), bool (True atau False).

perangkat = ["Router", "Switch", "AP"]      # list
perangkat.append("Server")
print(len(perangkat))                      # 4

ip = {"Router": "192.168.1.1",
      "Server": "192.168.1.10"}            # dictionary
print(ip["Server"])

nama = input("Nama perangkat: ")
try:
    jumlah = int(input("Jumlah: "))
except ValueError:

List menyimpan urutan data, dictionary menyimpan pasangan kunci dan nilai. try/except menangkap kesalahan supaya program tidak berhenti mendadak.

Menghitung subnet dengan Python

Python punya modul ipaddress yang membantu memeriksa hasil subnettingmu:

import ipaddress

net = ipaddress.ip_network("192.168.1.0/26")
print(net.netmask)               # 255.255.255.192
print(net.num_addresses - 2)     # 62
print(net.broadcast_address)     # 192.168.1.63

for host in list(net.hosts())[:3]:
    print(host)

Ganti prefix atau alamatnya dan bandingkan dengan hitungan manualmu.
